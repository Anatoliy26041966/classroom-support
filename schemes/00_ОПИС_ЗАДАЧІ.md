# Опис задачі: Рекомендаційна система зоопослуг (Cat App)

## Вхідні дані

- `Pet_Type` (Тип улюбленця): "Кіт", "Собака" тощо.
- `Breed_Type` (Тип шерсті): "Довгошерста", "Короткошерста".
- `Want_Groomer` (Потрібен грумер): "Так", "Ні".

## Логіка алгоритму (IF-ELSE-IF)

1. **Умова 1**: Якщо Кіт AND Довгошерста AND Грумер=Так
   => Вивести: "Надайте адресу найближчої котячої перукарні"
2. **Умова 2**: Якщо Кіт AND Довгошерста AND Грумер=Ні
   => Вивести: "Запропонуй магазин з товарами по догляду за шерстю"
3. **Умова 3**: Якщо Кіт AND Короткошерста
   => Вивести: "Запропонуй обрати магазин із зоотоварами"
4. **Умова 4 (Інакше / Немає Кота?)**
   => Вивести: "Коли вирішите завести улюбленця – приходьте"

# ОПИС ЗАДАЧІ: Cat App

[ЗМІННІ]
VAR1: pet_type (кіт, собака)
VAR2: breed_type (довгошерста, короткошерста)
VAR3: want_groomer (так, ні)

[ЛОГІКА]
IF pet_type == кіт AND breed_type == довгошерста AND want_groomer == так THEN
PRINT "Надайте адресу найближчої котячої перукарні"
IF pet_type == кіт AND breed_type == довгошерста AND want_groomer == ні THEN
PRINT "Запропонуй магазин з товарами по догляду за шерстю"
IF pet_type == кіт AND breed_type == короткошерста THEN
PRINT "Запропонуй обрати магазин із зоотоварами"
IF pet_type == собака THEN
PRINT "Коли вирішите завести улюбленця – приходьте"
ELSE
PRINT "Коли вирішите завести улюбленця – приходьте"
