# 🚀 Beet Seed / Beet Sprout — Performance & Stress Testing

Проєкт з навантажувального та стрес-тестування API за допомогою **Apache JMeter**.

## 📊 Зміст репозиторію
* `stress_test.jmx` — Тест-план Apache JMeter для стрес-тестування API та пошуку граничних навантажень.
* `performance_results.csv` — Логи та результати виконання навантажувальних тестів.
* `performance_results.md` — Детальний звіт із метриками продуктивності та аналізом результатів.

## 🛠️ Як запустити
1. Встановіть та запустіть **Apache JMeter**.
2. Відкрийте файл `stress_test.jmx`.
3. Налаштуйте групу потоків (Thread Group) для визначення кількості віртуальних користувачів та запустіть сценарій.
