# 📚 Портал підтримки Google Classroom

Централізований вебпортал для учнів, батьків та вчителів щодо роботи з Google Classroom, Google Meet та освітніми інструментами Google Workspace for Education.

---

## 🌟 Основні можливості

- **Динамічний пошук та фільтрація курсів:** Миттєвий пошук кодів приєднання за класом, предметом або назвою.
- **Копіювання кодів у 1 клік:** Зручне копіювання коду приєднання в буфер обміну.
- **Єдина динамічна шапка (Header):** Автоматична генерація меню навігації на всіх сторінках проєкту через `app.js`.
- **Форма зворотного зв'язку (Техпідтримка):** Відправка заявок про проблеми прямо в Google Таблицю через Google Apps Script API.
- **Моніторинг статусу сервісів:** Сторінка відстеження працездатності освітніх платформ.
- **Адаптивний дизайн:** Повністю оптимізовано під мобільні пристрої та ПК на базі Tailwind CSS.

---

## 📁 Структура проєкту

```text
classroom-support/
├── index.html              # Головна сторінка (Пошук курсів + Форма підтримки)
├── parents.html            # Розділ для батьків (Інструкції та підказки)
├── teachers.html           # Розділ для вчителів (Стандарти та чек-листи)
├── meet.html               # Інструкції з роботи з Google Meet та етикет
├── status.html             # Сторінка моніторингу статусу сервісів
├── app.js                  # Основна логіка: генерує header, керує фільтрами та формою
└── classroom-support/      # Папка для даних та допоміжних скриптів
    └── data.js             # Масив із даними про всі курси та коди приєднання
```
