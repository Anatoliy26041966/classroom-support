# SchoolGus Workspace — навчальний каталог

Це статичний **публічний** каталог курсів Google Classroom. Назви, секції,
ідентифікатори курсів і прямі посилання доступні без входу. Саме посилання не
надає доступу до матеріалів: доступ контролюють Google Classroom і політики
Workspace.

## Дані каталогу

Поточні `courses.json` і `classroom_courses.csv` містять лише поля:
`id`, `name`, `section`, `courseState` та `link`. Не додавайте до публічних
файлів і комітів email-адреси учнів чи працівників, списки учасників, коди
приєднання, власників курсів, облікові дані або іншу персональну інформацію.

Перед публікацією назв і секцій переконайтеся, що школа дозволяє їх показувати
публічно. Видалення даних із поточної версії не прибирає їх зі старих комітів.

## Оновлення

`classroom_courses.csv` — очищене джерело каталогу. Генератор залишає лише
активні курси, перевіряє посилання та дублікати й експортує лише дозволені
поля:

```bash
python3 update_portal_data.py
```

GitHub Actions щодня запускає генератор і публікує оновлений `courses.json` та
кеш Service Worker.

## Встановлення як додатка (PWA)

- **Android (Chrome):** меню `⋮` → «Додати на головний екран».
- **iOS (Safari):** «Поділитися» → «На початковий екран».
- **Комп’ютер (Chrome):** скористайтеся кнопкою встановлення в адресному рядку.

Для допомоги зверніться до внутрішньої IT-підтримки школи.
