# 🏫 SchoolGus Workspace — Навчальний портал та IT-Інструкція

Офіційний навчальний портал Гусятинської ЗОШ I-III ступенів для домену **@schoolgus.ukr.education**.

> 🚀 **ГОЛОВНИЙ ФАЙЛ УПРАВЛІННЯ ПОРТАЛОМ: `admin_menu.py`**
> 
> Для швидкого керування порталом, оновлення курсів, аудиту та відправки змін на GitHub ви використовуєте **один основний файл**.
> 
> **Команда запуску в Терміналі:**
> ```bash
> python3 admin_menu.py
> ```
> *(Усі інші процедури оновлення працюють повністю автоматично у фоні).*

---

## 🏗 1. Архітектура та основні файли проєкту

| Файл / Папка | Роль у системі | Опис та необхідний код |
| :--- | :--- | :--- |
| **`admin_menu.py`** | **ГОЛОВНИЙ ФАЙЛ** | Інтерактивна панель адміністратора. Запускається через `python3 admin_menu.py`. |
| **`index.html`** | ВЕБІНТЕРФЕЙС | Основна сторінка порталу (Bootstrap 5.3, розклад, форма підтримки, PWA). |
| **`courses.json`** | БАЗА ДАНИХ | Файл даних усіх 650+ курсів Google Classroom. |
| **`run_daily_update.sh`** | АВТОМАТИЗАЦІЯ | Bash-скрипт локального оновлення з Mac. Запуск: `./run_daily_update.sh`. |
| **`update_portal_data.py`** | СКРИПТ ДАНИХ | Зчитує курси та оновлює мітку часу в `courses.json`. |
| **`manifest.json` / `sw.js`** | PWA-МОДУЛЬ | Забезпечують можливість встановлення сайту як додаток на iOS/Android. |
| **`.github/workflows/`** | SERVER AUTO-SYNC | Скрипт GitHub Actions для щоденного оновлення сайту о 03:00 на сервері. |
| **`archive/`** | АРХІВ | Папка з допоміжними скриптами аудиту та безпеки груп. |

## 🎮 2. Інструкція користування `admin_menu.py`

При запуску `python3 admin_menu.py` ви отримуєте цифрове меню:

* **[1] 🔄 Оновити courses.json** — Оновлює список курсів та запевняє актуальність дати на сайті.
* **[2] 🔍 Аудит Google Classroom** — Запускає перевірку стану курсів та вчителів.
* **[3] 🛡 Безпека груп Workspace** — Перевіряє та застосовує правила безпеки груп домену.
* **[4] 👥 Наповнення груп** — Запускає скрипт розподілу користувачів за групами.
* **[5] 🚀 Відправити всі зміни в GitHub** — Автоматично робить `git add`, `git commit` та `git push` в один клік.
* **[0] ❌ Вихід** — Закриває меню.

## 🔄 3. Як працює автооновлення (Без вашої участі)

1. **На сервері GitHub (Щодня о 03:00):** GitHub Actions автоматично запускає `update_portal_data.py`, оновлює `courses.json` та публікує свіжий сайт.
2. **Фоново на MacBook (О 08:00):** Агент `launchd` запускає `./run_daily_update.sh` і фіксує результати у файлі `update.log`.

## 📲 4. Як встановити портал як додаток (PWA)

* **Android (Chrome):** Натиснути `⋮` $\rightarrow$ **«Додати на головний екран»**.
* **iOS / iPhone (Safari):** Натиснути кнопку `Поділитися` $\uparrow$ $\rightarrow$ **«На початковий екран»**.
* **Mac / PC (Chrome):** Натиснути іконку з плюсом/завантаженням в адресному рядку.

## 🛡 5. Кібербезпека та правила домену

1. **Без відкритих кодів:** Посилання та коди приєднання до Classroom приховано від публічного доступу.
2. **Аутентифікація:** Учні заходять у свої класи виключно через акаунти `@schoolgus.ukr.education`.
3. **Техпідтримка:** Усі запити надсилаються на `support@schoolgus.ukr.education`.
