# 🏫 SchoolGus Workspace — Навчальний портал

Офіційний навчальний портал Гусятинської ЗОШ I-III ступенів для домену **@schoolgus.ukr.education**.

## 🌟 Основні можливості

- 📚 **Каталог курсів:** Зручний пошук та фільтрація курсів Google Classroom по класах (1-11) та предметах.
- 📱 **PWA Support:** Можливість встановлення порталу як додатка на смартфони (iOS/Android) та ПК.
- 🔒 **Кібербезпека:** Повна відповідність політикам безпеки домену Google Workspace (без відкритих кодів та посилань Meet).
- 🛠 **Служба підтримки:** Пряма інтеграція форми з `support@schoolgus.ukr.education`.
- ⏰ **Розклад дзвінків:** Інтегрований розклад 1–7 уроків.
- ⚡ **Автоматизація:** Щоденне фонове оновлення даних через GitHub Actions та macOS launchd.
